# 퀀트 투자 입문 강의 노트

이현열 교수님의 유튜브 퀀트 투자 강의를 들으며 **직접 정리한 공부 노트**입니다. 강의 내용을 제 말로 요약하고, 이해한 내용을 덧붙였습니다.

- 강의: 이현열 교수님 유튜브 퀀트 투자 강의
- 함께 공부한 책: 이현열, 『파이썬을 이용한 퀀트 투자 포트폴리오 만들기』 (책 코드 저장소: https://github.com/hyunyulhenry/quant_py)

> 강의 화면이나 책 본문·코드는 옮기지 않았고, 정리한 글만 올립니다. 내용에 오류가 있다면 제 이해가 부족한 탓입니다.
